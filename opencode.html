Executive Incident Summary

00:00 - 08:50
  • The Attack: Attackers targeted a legacy OpenCode web system, extracting API keys (OpenAI, Anthropic, Google) saved by ~1.4% of users in the web console.
  • Model Distillation: Stolen API keys were leveraged to run massive queries, extracting knowledge from proprietary frontier models to train smaller open weights.
  • Financial Impact: Users suffered surprise charges ranging from hundreds to thousands of dollars; several cloud projects were suspended.
  • Official Response: Founder Dax Raad confirmed refunds are underway. Local terminal-based CLI apps remain safe and unaffected.

Actionable Safety Rules

Revoke exposed API keys immediately, assign unique keys per app, enforce hard spending caps, and establish automated usage threshold alerts.
